# Кандидаты и цикл предложений (фаза 4)

`/propose` (или кнопка «Подобрать предложения») запускает `agent.candidates.ProposalCycle`:

1. Проверки: права (`BOT_ALLOWED_USER_IDS`), значения владельца (`HURDLE_CPA_TON`, `EXPLORE_SHARE`,
   `MAX_LOSS_PER_HYPOTHESIS`, `MAX_ACTIVE_EXPERIMENTS`), allow-list ссылок, место в очереди
   (`MAX_PENDING_PROPOSALS`), свободный бюджет и слоты (`BudgetPlanner`). Если чего-то нет, ответ —
   «Предложений нет: <причина>», значения не угадываются.
2. Генераторы:
   - **history** — лучшие прошлые объявления (по CPA, затем CPC), мутация ровно одного фактора:
     CPM ± шаг, креатив, группа гео, тема;
   - **grid** — `config/geo_pool.yaml`: базовая связка + по одному фактору (группа гео, тема, креатив);
   - **ledger** — `data/external_placements.csv`: каналы с самой дешёвой стоимостью вступления как
     таргет `channels`; относительная стоимость даёт сдвиг приора CVR (σ = `AGENT_EXTERNAL_PRIOR_SIGMA`).
3. Дедупликация по отпечатку (раздел 9): живые объявления, недавно завершённые (последний раз были
   активны в пределах `AGENT_DEDUP_DAYS`), ожидающие решения и недавно отклонённые/исполненные предложения.
   Сравниваются оба варианта угла креатива: метка из `creatives.yaml` и хеш текста.
4. Скоринг: `score = P(CPA < c*) · V / C_stage`, отсев `P < τ_min`, жадный набор в пределах
   `explore_cap`, не больше одного изменённого фактора относительно контрольной связки того же типа таргета.
5. Контроль (7.8): если в батче ≥ 2 теста и хватает слотов/бюджета, добавляется повтор лучшего
   известного объявления (если оно не активно сейчас).
6. Предложения создаются через `ProposalService.create` (валидатор + резерв). Ничего не исполняется
   без «Принять».

## Файлы владельца (все необязательные)

| Файл | Шаблон | Если нет |
|---|---|---|
| `config/geo_pool.yaml` | `config/geo_pool.example.yaml` | сетка не строится |
| `data/external_placements.csv` | `data/external_placements.example.csv` (только заголовок) | каналы не предлагаются |
| `config/creatives.yaml` | `config/creatives.example.yaml` | используются тексты прошлых объявлений |

Базовый CPM для новых ячеек: CPM лучшего прошлого объявления → `base_cpm` в `geo_pool.yaml` →
`AGENT_BASE_CPM`. Если нигде нет, сетка и ledger не строятся (замечание в ответе).
